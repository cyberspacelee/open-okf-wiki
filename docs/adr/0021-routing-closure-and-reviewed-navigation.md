# Routing closure and reviewed navigation

Status: accepted

The `artifact-loop-routing-closure` contract makes the information architecture reviewable before page fan-out: integration units scope and seed every participating Source, Catalog evidence remains inside the selected table scope, Plan and Composition reviews record merge probes covering every routed item, multi-page Compositions use capability directories, and multi-unit pages carry their merge rationale. Domain pages retain ownership and invariants while the new Procedure type owns internal orchestration, formulas and algorithms. Candidate construction generates the Navigation Index before final review, while drafts remain flat by stable Page ID so a move changes only Composition. Catalog storage uses a readable Source prefix plus a short hash for the directory and retains the full SHA-256 as the verified identity. Legacy Runs are rejected; OKF remains v0.2.
